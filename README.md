# Odin Recipes

Project from The Odin Project's Foundations course. A simple multi-page 
site with 3 recipes (Milanesa napolitana, Pizza, Tacos), each with 
description, ingredients, and step-by-step instructions.


## Live demo
https://gnazarenobernate.github.io/recipes/


## Stack
- HTML5 (semantic)

## What I practiced
- Relative file paths between pages
- HTML5 structure
- Nested lists (ordered/unordered)
- Image attribution (Pexels, Unsplash, free-to-use)
- Internet research (before asking people and/or AI)
- MDN Web Docs usage when lost 
- Good habits with Git/Github (constant commits, good commit messages)
